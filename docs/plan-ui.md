# 活动栏与面板规划

> **这是设计草稿，描述的是规划而不是现状。** 原文件名为 `docs/ui.md`，正文是一段笔记体条目清单，已按"规划 / 现状"整理成对照表。
> **已实现部分的行为以 [`client.md`](client.md) 为准** —— 其中有几项与当初的规划并不一致，对照表已标出，那些差异是实际演进的结果，不是待修的缺陷。

活动栏按钮分为两类：控制侧边栏的，和其他。

## 控制侧边栏

| 面板 | 规划 | 现状 |
|---|---|---|
| `searchpanel` | 搜索 | 已实现，但形态改了：是**全屏命令面板**（`Ctrl/Cmd+P`）而不是侧边栏面板 |
| `treepanel` | 普通的按名称排序、无法修改 | 已实现，但语义加强了：按 `date` 倒序，且支持拖拽移动、重命名、建子节点、自定义图标 |
| `tagspanel` | 列出所有标签，点击标签返回仓库内笔记列表 | 已实现侧边栏面板；"点击标签列出笔记"落在全局搜索面板里（点标签 → 切换为按标签过滤） |
| `calendar` | 铺满一整列 | **未实现** |

## 其他

| 按钮 | 规划 | 现状 |
|---|---|---|
| `overview` | 笔记数量、日期分布、静态资源总大小与数量、各标签所含笔记数 | **未实现** |
| `setting` | 设置 | **未实现**。主题切换目前直接放在活动栏底部 |
| 附件 / 回收站 | 规划中未列出 | 已实现：由活动栏按钮切换侧边栏面板 |

## 待定

- `calendar` 与 `overview` 都需要"仓库级统计"，当前接口没有任何聚合能力；实现前需要先定 API（见 [`api.md`](api.md)）。
- `setting` 面板与"配置全部硬编码在 `server/config.go`"的现状冲突：目前没有运行时可变配置，面板若要落地需先决定哪些配置允许改。
