## 配置硬编码 + 后端托管自动更新图标集

诉求：后端不要 .env，端口 / icon 存放位置 / webnotes 存放位置等配置全部硬编码进代码；图标改由后端托管并自动更新。

改动：
- 新增 `server/config.go`：`Addr=:8080`、`DataDir=../data`（相对 server/，因 go.mod 在 server/）、`IconDir=../data/icons`、`IconFile=mdi.json`、`IconCheckInterval=24h`、`IconMinCount=1000`、`IconSources`（jsDelivr gh → fastly → GitHub raw）；`resolvePaths()` 相对路径解析 + 工作目录守卫（上级没有 server/ 直接报错，避免静默在别处新建 data/）。
